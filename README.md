# OMDb Api Movie Search

Веб-приложение для поиска фильмов с использованием OMDb Api.

## Демо

[Живое демо](https://movie-search-delta-virid.vercel.app/)

## Функциональность API

- Поиск фильмов по названию с автопоиском (задержка 1000мс)
- Отображение информации о фильмах (Название, постер, год)
- Адаптивный дизайн с анимациями
- Состояние загрузки с анимированным спиннером
- Обработка ошибок с кастомным компонентом
- Кликаемый логотип для сброса поиска

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/FlintAB/movie-search.git
   ```

2. Установите зависимости:
   ```bash
   npm i
   ```

3. Создайте файл .env в корне проекта и добавьте ключ OMDb API:
   ```plaintext
   VITE_OMDB_API_KEY=вставьте_ваш_ключ
   ```

4. Запустите приложение:
   ```bash
   npm run dev
   ```
